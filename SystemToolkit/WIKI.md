## 🚀 快速开始

### 安装要求

- **操作系统**: Windows 10/11 (64 位)
- **运行库**: .NET 10.0 Runtime
- **内存**: 最低 2GB RAM，推荐 4GB
- **磁盘**: 100MB 可用空间

### 下载安装

#### 方式 1: 从 GitHub Releases 下载

1. 访问 [Releases 页面](https://github.com/SamHub1991/NetTool/releases)
2. 下载最新的 `SystemToolkit-v*.zip` 文件
3. 解压到任意目录
4. 双击运行 `SystemToolkit.App.exe`

#### 方式 2: 从源码编译

```bash
git clone https://github.com/SamHub1991/NetTool.git
cd NetTool/SystemToolkit
dotnet restore
dotnet build -c Release
dotnet run --project SystemToolkit.App
```

### 首次使用

启动应用后，您会看到左侧的导航菜单，包含所有功能分类。点击任意功能即可查看和使用。

> 💡 **提示**: 部分功能（如服务管理、进程终止）需要管理员权限。如需使用这些功能，请右键应用选择"以管理员身份运行"。

## 📖 功能详解

### 1. 文件管理

#### 批量重命名
**用途**: 快速重命名多个文件

**操作步骤**:
1. 选择目标文件夹
2. 设置重命名规则：
   - 搜索和替换文本
   - 添加前缀或后缀
   - 使用正则表达式（高级）
3. 点击"加载文件"预览
4. 确认无误后点击"执行重命名"

**示例场景**:
- 将 `IMG_001.jpg`, `IMG_002.jpg` 重命名为 `Vacation_001.jpg`, `Vacation_002.jpg`
- 移除文件名中的特殊字符

#### 文件去重
**用途**: 查找并删除重复文件，释放磁盘空间

**工作原理**: 使用 SHA256 哈希算法识别内容完全相同的文件

**操作步骤**:
1. 选择要扫描的目录
2. 点击"开始扫描"
3. 查看重复文件列表
4. 选择要删除的副本
5. 点击"清理选中文件"

#### 大文件查找
**用途**: 快速定位占用空间的大文件

**操作步骤**:
1. 选择扫描目录
2. 设置最小文件大小（如 100MB）
3. 点击"扫描"
4. 按大小排序查看结果

### 2. 网络工具

#### Ping 工具
**用途**: 测试网络连通性

**操作步骤**:
1. 输入目标主机（域名或 IP）
2. 点击"开始 Ping"
3. 查看结果：
   - ✅ 成功：显示往返时间和 TTL
   - ❌ 失败：显示错误信息

#### 端口扫描
**用途**: 检测目标主机开放的端口

**支持范围**: 1-65535 端口

**操作步骤**:
1. 输入目标主机
2. 选择扫描范围：
   - 快速扫描（常用端口 1-1000）
   - 全端口扫描（1-65535，耗时较长）
3. 点击"开始扫描"
4. 查看开放的端口和服务名称

#### HTTP API 测试
**用途**: 测试 REST API 接口

**功能**:
- 支持 GET、POST、PUT、DELETE 等方法
- 自定义请求头
- 请求体编辑（JSON/XML）
- 响应时间和状态码显示

## ❓ 常见问题

### Q1: 为什么部分功能无法使用？

**A**: 部分系统级功能需要管理员权限。请右键点击应用，选择"以管理员身份运行"。

### Q2: 如何批量重命名文件？

**A**: 
1. 进入"文件管理" → "批量重命名"
2. 选择目录
3. 设置规则（如：搜索"old"替换为"new"）
4. 预览后执行

### Q3: 文件去重安全吗？

**A**: 非常安全。工具使用 SHA256 哈希算法，只有内容完全相同的文件才会被识别为重复。建议先备份重要数据。

### Q4: 端口扫描为什么很慢？

**A**: 全端口扫描（1-65535）需要检测每个端口，耗时较长。建议使用"快速扫描"模式检测常用端口。

### Q5: 监控系统资源时 CPU 使用率为什么是 0？

**A**: 某些系统需要管理员权限才能读取性能计数器。请以管理员身份运行应用。

### Q6: 应用闪退怎么办？

**A**:
1. 确保已安装 .NET 10.0 Runtime
2. 检查 Windows 事件查看器中的错误日志
3. 在 GitHub Issues 提交问题报告

### Q7: 如何报告 Bug 或建议新功能？

**A**: 请访问 GitHub Issues: https://github.com/SamHub1991/NetTool/issues

## 🛠️ 开发指南

### 添加新功能

1. 在 `SystemToolkit.Core/Services` 创建服务接口和实现
2. 在 `SystemToolkit.App/ViewModels` 创建视图模型
3. 创建对应的 XAML 视图或 UserControls
4. 在 `MainViewModel.cs` 中注册到菜单

### 代码规范

- 遵循 C# 命名约定
- 所有 I/O 操作使用异步
- View 层使用 MVVM 模式
- 公共服务必须实现接口

### 运行测试

```bash
dotnet test SystemToolkit.Tests
```
